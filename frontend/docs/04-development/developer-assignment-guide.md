---

## Process

1. Select sprint from `sprint-tracker.md` (dependency Completed).
2. Check the sprint file prerequisites / BLOCKER.
3. Assign **one** developer (update tracker).
4. Create `feature/sprint-{number}-{short-name}` from `dev`.
5. Give the sprint markdown to the developer.
6. Developer reads requirements; escalates UNKNOWN to Team Lead.
7. Developer implements **frontend** only. Mock until API exists.  
   **Backend dependency: frontend will consume the available backend/API service.**
8. Developer tests the sprint checklist.
9. PR to `dev` with title `[Sprint XX] …`.
10. Reviewer reviews.
11. Developer fixes comments.
12. Approve.
13. Merge to `dev`.
14. QA.
15. Status = Completed.
